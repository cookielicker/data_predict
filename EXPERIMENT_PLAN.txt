【Phase 1】诊断阶段 (2小时)
─────────────

Step 1: 改进FC模型 (30分钟)
  □ 运行: python train/train_fc_improved.py
  □ 记录最终准确率
  □ 截图训练曲线或最后几行输出
  
  👉 判断:
    如果上升到 65%+ → 问题是学习率, FC可以接受
    如果仍在 55% → 问题是架构, 需要改用LSTM/Transformer

Step 2: 训练LSTM (40分钟)
  □ 运行: python train/train_unified.py --model lstm
  □ 记录最终准确率
  □ 观察收敛速度 (学习曲线)
  
  👉 判断:
    如果 70%+ → LSTM有效, 序列模型有帮助
    如果 55% → LSTM也不行, 可能是特征问题

Step 3: 训练Transformer (40分钟)
  □ 运行: python train/train_unified.py --model transformer
  □ 记录最终准确率
  □ 对比LSTM vs Transformer
  
  👉 判断:
    如果Transformer > LSTM → Transformer是最佳选择
    如果接近 → LSTM更简单, 选LSTM


【Phase 2】分析阶段 (1小时)
──────────

基于Phase 1的结果，选择改进方向:

情景 A: 三个模型都很差 (都<60%)
───────────────────────────
  原因: 特征本身问题
  解决: 
    □ 运行 python diagnose_features.py
    □ 检查特征统计分布
    □ 添加特征标准化/归一化
    □ 重新训练

情景 B: FC < LSTM < Transformer
──────────────────────────────
  原因: 架构确实很重要
  解决:
    □ 使用Transformer作为最终模型
    □ 进行超参数优化 (下一阶段)

情景 C: 三个模型差不多 (~60-65%)
────────────────────────────
  原因: 特征信息有限 + 任务困难
  解决:
    □ 特征工程 (添加更多特征)
    □ 加入更多技术指标
    □ 融合外部信息


【Phase 3】优化阶段 - 可选 (2-4小时)
────────────────────────

确定最佳架构后 (假设是Transformer), 进行超参数优化:

□ 尝试不同的学习率
  python train/train_unified.py --model transformer --lr 0.00005
  python train/train_unified.py --model transformer --lr 0.0001
  python train/train_unified.py --model transformer --lr 0.0005
  
  → 找到最优学习率

□ 尝试不同的batch size
  python train/train_unified.py --model transformer --batch_size 32
  python train/train_unified.py --model transformer --batch_size 128

□ 尝试不同的模型大小
  (编辑 train_unified.py 修改 d_model, num_layers 等参数)
  
  d_model: 64, 128, 256 → 更大 = 更强但更慢
  num_layers: 2, 3, 4, 5 → 更深 = 更强但容易过拟合
