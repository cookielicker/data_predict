# 16_三板组识别_东财财富号

> 来源：https://caifuhao.eastmoney.com/news/20260319050148166167340

---

三板组（三板主）是A股短线游资/短庄的俗称，核心是3板内完成诱多+出货，走“首板急拉→二板一字→三板砸盘”套路。给你一套可直接用的识别方法。
一、先看市值（最核心）
- 自由流通市值：≤20亿（优先看10–15亿）
- 总市值：≤30–50亿
- 排除：30亿以上基本不看
二、看连板走势（一眼识别）
- 首板：90直线秒拉、几乎无震荡、封单巨大（常超流通盘10%）
- 二板：一字板/T字板、封单更夸张、全天几乎不撤单
- 三板：高开/一字开盘→9:30前后突然撤单→垂直跳水、日内振幅15%+、天地板/长阴巨量
- 后续：A杀连续阴跌
三、看换手与筹码
- 前两板换手极低：<5%，常见**1%–2%**极致缩量
- 筹码高度锁死、浮筹极少
- 三板突然巨量换手（出货信号）
四、看封单特征
- 封单远超合理值，甚至大于流通市值
- 程序单特征：9:15:01后才挂单、反复撤单再挂、制造抢筹假象
- 三板开盘瞬间封单集体消失
五、看龙虎榜席位（辅助验证）
- 常见关联席位：
- 联储证券宁波解放南路/宁波分公司
- 华源证券深圳深南东路/深圳分公司
- 天风证券江阴人民东路/人民中路
- 光大证券武汉中北路
- 多个席位同时出现、联动买入，且无机构、多为游资
六、一句话速记口诀
小盘低换手，直线拉涨停；巨额封单诱多，三板小心砸盘
七、风险提示
三板组股票风险极高：给你机会买时，往往就是主力出货、接盘的时候，极易深度套牢 。
最经典、最标准的三板组（游资短庄）案例，全是3板内完成诱多+出货、A杀暴跌的典型。
一、王力安防（605268）—— 教科书级三板组
- 时间：2026年3月
- 市值：流通盘极小（大股东持股超80%，实际流通仅约5亿）
- 走势：
- 首板：90秒拉封板，换手极低
- 二板：一字/T字板，封单巨大、散户买不到
- 三板：高开秒板→开盘瞬间撤单→垂直跳水，天地板/长阴巨量
- 结局：三板后连续A杀，追高者2天亏25%+
二、美邦股份（605033）—— 同一资金、两次收割
- 时间：2025年7月、2026年2月（两次一模一样）
- 手法：
- 首板放量，二、三、四板缩量一字，不给散户机会
- 第4–5板：竞价一字→开盘撤单→天地板出货
- 换手：前几板**<3%，出货日>20%（实际换手超80%**）
- 结局：两次都是天地板+连续跌停，追高者一周亏40%+
三、瑞尔特（002790）—— 五板组（三板组变种）
- 时间：2025年10–11月
- 走势：
- 10.27–10.31：连续4个缩量一字，日均换手**<3%**
- 11.3：一字开盘→9:31突然撤单→6分钟砸到跌停
- 全天振幅19.8%，换手28.14%
- 结局：4天从13.22→9.10，跌幅31%，打板资金全被套
四、庄园牧场（002910）—— 典型三板A杀
- 时间：2025年12月
- 走势：
- 首板秒板、二板一字
- 三板：高开低走、巨量换手，主力出货
- 次日：直接低开低走、跌停
- 结局：三板追入者次日亏15%+，随后阴跌不止
五、华科材料（非上市）—— 三无题材三板杀猪
- 时间：2025年11月
- 特征：无利好、无题材、无业绩，纯资金推动
- 走势：
- 3连板从8.3→11.1
- 三板爆量、散户追入
- 第四日高位十字星（诱多）
- 第五日低开跌停，2天亏20%+
三板组共同特征（对照复盘）
- 市值：流通≤20亿（优先10亿以下）
- 连板：首板秒拉→二板一字→三板爆量砸盘
- 换手：前两板**<5%，三板>20%**
- 封单：前两板巨量封单，三板开盘瞬间消失
- 龙虎：多为宁波/深圳/江阴等三板组关联席位
- 结局：A杀连续跌停，无反弹
