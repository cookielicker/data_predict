# 08_情绪周期七阶段_新浪

> 来源：https://www.sina.cn/news/detail/5347063085926950.html

---

短线操作赚钱的法宝——情绪周期情绪周期的本质，是短线资金在赚钱效应、亏钱效应之间循环往复的过程：赚钱效应→亏钱效应→再度修复。周期划分没有绝对统一标准，实战普遍分为七个阶段：冰点—启动—发酵—高潮—分歧—退潮—修复。节点日就是情绪发生阶段切换的关键交易日。交易的核心不是提前预测拐点，而是依靠多指标共振、龙头走势验证，再通过次日盘面确认，杜绝主观臆测。一、情绪周期七阶段冰点期：跌停数量多、涨停稀少，连板个股大面积被杀，市场亏钱效应走到极致。节点信号：跌停潮之后出现止跌，老龙头不再遭遇核按钮。操作应对：轻仓小仓位试错。启动期：新题材批量走出首板，涨停家数回升，昨日涨停溢价由负转正。节点信号：冰点过后迎来首板潮，新题材龙头打出首板、二板。操作应对：试错新主线题材。发酵期：龙头持续连板，板块梯队完整，个股晋级率明显抬升。节点信号：龙头走到3板附近，板块形成2‑3‑4板完整梯队。操作应对：加仓，持有主线龙头。高潮期：涨停家数大幅增加，一字板扎堆，板块补涨股遍地开花。节点信号：各类情绪指标到达极值，主线龙头进入加速阶段。操作应对：逢高减仓，兑现利润。分歧期：龙头放量开板，中位股大面积吃面，个股晋级率下滑。节点信号：市场迎来第一次大分歧，炸板率明显走高。操作应对：去弱留强，抛弃弱势标的。退潮期：龙头跌停被核按钮，连板梯队直接断档，跌停数量再度增加。节点信号：主线龙头行情终结，亏钱效应向全市场扩散。操作应对：空仓防守，严控风险。修复期：跌停数量回落，老龙头止跌企稳，新题材首板开始涌现。节点信号：退潮末尾出现新题材批量首板。操作应对：小仓位试错新周期。需要注意，大周期内部会嵌套小周期，单一题材的周期，和大盘整体情绪周期经常会出现不同步。二、节点日怎么确定节点日包含冰点日、启动日、确认日、加速日、高潮日、分歧日、退潮日、修复日。判断遵循四条原则：第一，多指标共振。每日跟踪记录：涨停数、跌停数、炸板率、封板率、连板家数、市场最高板、晋级率、昨日涨停今日溢价、大面个股数量、龙头状态、新题材出现数量。第二，龙头与题材验证。老龙头结束的日子，往往就是退潮节点；新题材批量首板，大多对应启动节点；龙头确认走出连板，属于发酵确认节点。第三，指数与量能辅助。放量修复的信号可信度更高，缩量退潮风险更大；指数和情绪共振，会放大行情的波动幅度。第四，收盘确认叠加次日验证。启动日要看次日的溢价和晋级情况；退潮日要看次日会不会出现核按钮；分歧日要看次日能否完成修复。三、常见节点信号参考冰点日：涨停数量少、跌停数量多，连板个股个位数，市场最高板不超过3板，炸板率大于40%，昨日涨停出现负溢价。启动日：冰点之后涨停家数回升，新题材首板达到5‑10家，跌停数量下降，市场溢价转正。确认日：龙头走到3板附近，板块梯队完整，晋级率高于50%，炸板率回落。高潮日：涨停家数80‑100家以上，连板个股20家以上，市场最高板大于5板，一字板增多，补涨个股遍地。分歧日：龙头放量开板，中位股出现大面积亏损，炸板率大于30%，个股晋级率下滑。退潮日：龙头跌停遭遇核按钮，连板数量骤减，跌停增多，昨日涨停为负溢价。修复日：跌停数量减少，老龙头止跌，新题材首板出现，但行情还没有进入高潮。以上阈值会跟随市场风格动态变化，不能死板照搬。四、每日判断完整流程1. 收盘之后统计全部情绪指标。2. 梳理情绪温度变化，寻找极值与拐点。3. 判断市场龙头处在生命周期的哪个阶段。4. 观察是否出现新题材批量首板，或是老题材集体退潮。5. 依靠次日开盘盘面验证，观察溢价、个股晋级、核按钮、炸板率变化。6. 确认情绪节点之后，对应调整自身仓位。五、核心口诀冰点看止跌，启动看新题材，发酵看梯队，高潮看一致，分歧看龙头，退潮看核按钮，修复看新首板。节点日并不是每个交易日都会出现，只有情绪方向发生质变的时候才会形成。实战交易宁可滞后确认信号，也不要提前主观臆测拐点。以上仅为短线交易思路复盘，不构成投资建议，股市有风险，入市需谨慎。
